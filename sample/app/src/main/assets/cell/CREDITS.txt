Runtime network (not bundled):

                 (https://www.esri.com/; free basemap, no key).
  Cell positions OpenCelliD              — CC-BY-SA 4.0 (https://opencellid.org).
                 Looked up at runtime by (MCC,MNC,LAC/TAC,CID) ONLY when an API key
                 is configured (local.properties → octet.openCellIdKey). The database
                 is NOT redistributed/bundled; cells the DB does not know fall back to
                 an on-device ESTIMATED position, clearly badged. No key → all estimated.

Cell tower positions are never exposed by the OS. This screen is a visualization of
observed cells; it is not a location proof.
